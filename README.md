Prosthetic technology is often expensive and inaccessible, limiting its reach to those who need it most. To address this, I am developing a low-cost, functional, and intelligent prosthetic arm using myoelectric control and deep learning.
This project is based on the open-source InMoov robotic arm, modified for affordability and real-world usability. By integrating EMG sensors, a NodeMCU microcontroller, and a Temporal Convolutional Network (TCN) model, the prosthetic accurately classifies muscle signals for natural and real-time gesture control. The design incorporates servo motors and a fishing-line tendon system to replicate muscle movement, while 3D printing ensures an ergonomic and cost-effective build.
The goal is to create a lightweight, intuitive, and adaptive prosthetic that enhances mobility and accessibility. Future developments include multi-channel EMG integration, AI-driven adaptive learning, wireless control, and enhanced sensory feedback.
This project is a work in progress, with continuous improvements aimed at making advanced prosthetic solutions more affordable and widely available
